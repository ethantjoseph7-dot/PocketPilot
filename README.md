# PocketPilot 💸

**A personal finance dashboard to help you make every rupee count.**

PocketPilot helps you record income and expenses, keep an eye on your monthly spending, and work toward a savings goal.

## Features

- **Dashboard overview** — balance, total income, expenses, and savings rate
- **Transaction tracker** — record income or expenses with categories and dates
- **Cash-flow chart** — compare income and spending across the last six months
- **Monthly budget** — set a limit and see how much you have spent
- **Savings goal** — name a goal, set a target, and add savings as you go
- **Quick insights** — see your top spending category and average expense
- **CSV export** — download your transactions for a spreadsheet
- **Browser storage** — entries are saved locally in your browser

## Built with

- HTML
- CSS
- Vanilla JavaScript
- Browser Local Storage

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

No build tools or package installation are required.

## Notes

- The dashboard uses Indian rupees (INR).
- Your transaction data stays in the browser on the device you use. It does not sync between devices.
- This is a personal tracking tool, not financial advice.
